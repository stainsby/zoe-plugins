   log.** *Adding to yourself* now says a director's standing direction, including any given at

   ```
   Each in the director's own words, dated. Added when given. Never edited. Removed only by a
   director.

   - {2026-01-01, <name>: "<their words>"}
   ```

   to

   ```
   Each a direction, stated plainly; who gave it, when, and in what words is in the log. Added
   when given. Changed or removed only on a director's word.

   - {one direction}
   ```

   **What to do:** replace those two description lines in your own enterprise instructions with
   the new two. Then, for each standing direction there: make sure your log has an entry with the
   director's own words, who gave it and when, adding one from the current entry if not; draft a
   plain wording for it, and put the drafts to a director. Replace each entry only once a director
   accepts its wording; until then it stays as it is. If one of your own skills points at a
   direction by its date, point it at the direction itself.
