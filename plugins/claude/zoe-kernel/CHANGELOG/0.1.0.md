## 0.1.0 — first recorded baseline

The first version with a recorded immutability baseline and size measure (743 lines /
6123 words / 36000 bytes over `kernel/`), established 2026-06-13.

**Pre-0.1.0 bootstrap — partial record.** The shape of 0.1.0 is knowable (the baseline
manifest and size are recorded), but the sequence of pre-0.1.0 changes that produced it is
not: the version-control history before the bootstrap commit is squashed and there are no
earlier version tags.

**Migration:** an adopter on a pre-0.1.0 / "~v1" kernel should diff their tree directly
against the 0.1.0 baseline manifest.
